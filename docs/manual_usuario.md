# Manual de Usuario - PharmaCRM

## 1. Introducción
Bienvenido a **PharmaCRM**, el sistema integral de gestión para farmacias independientes en Colombia. Este manual le guiará a través de las funciones principales del sistema.

## 2. Acceso al Sistema
Para ingresar al sistema:
1. Abra su navegador y diríjase a `http://localhost/hospital`.
2. Ingrese su nombre de usuario y contraseña.
3. Haga clic en "Iniciar Sesión".

### Roles de Usuario:
- **Administrador**: Acceso total a todas las funciones y configuraciones.
- **Supervisor**: Gestión de inventarios, reportes y visualización de ventas.
- **Cajero**: Acceso principal al Punto de Venta (POS) y registro de clientes.

## 3. Módulos Principales

### 3.1 Dashboard
Al ingresar, verá un resumen de:
- Ventas del día.
- Alertas de stock bajo.
- Próximos vencimientos de medicamentos.
- Gráficos de rendimiento mensual.

### 3.2 Punto de Venta (POS)
Para realizar una venta:
1. Busque el producto por nombre o escanee el código de barras.
2. Seleccione la cantidad.
3. Identifique al cliente (opcional para acumular puntos).
4. Seleccione el método de pago (Efectivo, Tarjeta, Transferencia).
5. Finalice la venta y genere el comprobante.

### 3.3 Inventario
- **Productos**: Visualice el catálogo completo, precios y existencias.
- **Categorías**: Clasifique sus productos (Analgésicos, Antibióticos, etc.).
- **Proveedores**: Gestione su lista de contactos para pedidos.

### 3.4 Clientes y Lealtad
- Registre nuevos clientes con su número de cédula.
- El sistema asignará puntos por cada compra que podrán ser redimidos posteriormente.
- Consulte el historial de compras de cada paciente.

### 3.5 Alertas
Preste atención a las notificaciones en la barra superior:
- **Rojo**: Producto agotado o vencido.
- **Amarillo**: Stock bajo o próximo a vencer (menos de 30 días).

## 4. Soporte
Para asistencia técnica, contacte al administrador del sistema.
